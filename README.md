# Circle Hook

The marketing site for Circle Hook LLC, a web design and development studio focused on regulated financial services.

Built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui. Deployed on Vercel.

## Getting started

Install dependencies:

```bash
npm install
```

Copy the environment file and fill in your values:

```bash
cp .env.example .env.local
```

Run the dev server:

```bash
npm run dev
```

The site runs at http://localhost:3000.

- Next.js 15 with App Router
- TypeScript
- Tailwind CSS
- shadcn/ui

- Vercel for hosting
